# NODO — 100% Offline AI Agent (Hack47 OFFGRID)

> Repositorio oficial del proyecto **NODO** para el Hackathon **Hack47 OFFGRID**.

## Estructura del Proyecto

- `nodo/`: Aplicación principal (React 19, TypeScript, Vite, Tailwind CSS, WebLLM WebGPU, Transformers.js ONNX, Pyodide WASM, Dexie IndexedDB).
- `app/`: Shell nativa de Android (Kotlin, Jetpack, WebView con WebGPU, almacenamiento offline).
- `public/packs/emergencia/`: Pack de supervivencia médica y primeros auxilios offline.
